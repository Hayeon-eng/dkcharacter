# Office Villain Test

회사 동기들끼리 돌리는 캡쳐용 오피스 빌런 유형 테스트입니다.

## 실행

```bash
# 별도 빌드 없음
open index.html
```

또는 GitHub Pages에 레포 루트 그대로 배포하면 됩니다.

## 파일 구성

- `index.html` - 앱 엔트리
- `style.css` - iOS 젤리/스티커 스타일 UI
- `main.js` - 질문, 결과 타입, 렌더링 로직

## 특징

- 10개 빌런 유형
- MBTI식 클릭 진단
- 궁합/상극 유형
- 결과 화면 이미지 저장 버튼
- 모바일 캡쳐에 최적화된 세로형 UI
