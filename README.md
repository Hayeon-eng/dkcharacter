# 오피스 빌런 테스트

GitHub 웹 업로드 안전 버전입니다.

## 파일 구조

```txt
index.html
style.css
main.js
package.json
README.md
```

PNG, assets 폴더, base64 이미지가 없습니다.

## GitHub 업로드

1. ZIP 압축을 풉니다.
2. GitHub 레포에서 Add file > Upload files로 이동합니다.
3. 위 5개 파일만 선택해서 업로드합니다.
4. Commit changes를 누릅니다.

GitHub Pages를 쓸 경우 Settings > Pages에서 main/root를 선택하면 됩니다.
