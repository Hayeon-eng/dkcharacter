# Office Villain Test

회사 동기들끼리 하는 오피스 빌런 유형 테스트입니다.

## 파일 구조

```txt
index.html
style.css
main.js
README.md
```

## 실행

별도 설치 없이 `index.html`을 열면 됩니다.

## 배포

### GitHub Pages

1. 이 파일들을 레포 루트에 업로드
2. Settings > Pages
3. Deploy from branch
4. main / root 선택

### Render Static Site

- Build Command: 비워두기 또는 `echo static`
- Publish Directory: `.`

## 주의

이 프로젝트는 정적 HTML/CSS/JS 사이트라서 `npm install` 또는 `npm run build`가 필요 없습니다.
